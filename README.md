# WinForms Practice Projects

A collection of small C# Windows Forms applications created to practice desktop application development, event-driven programming, UI design, and application logic using .NET Framework.

## Projects

### Tic Tac Toe

A two-player Tic Tac Toe game with a graphical Windows Forms interface.

Features:

- Local two-player gameplay
- X and O turn switching
- Win detection for rows, columns, and diagonals
- Draw detection
- Winning cells highlighting
- Restart game functionality

Location:

```text
TicTacToe/
```

---

### Pizza Restaurant UI

An interactive pizza ordering application that calculates an order based on the selected options.

Features:

- Pizza size selection
- Multiple toppings
- Thin or thick crust
- Eat-in or take-out
- Quantity selection
- Dynamic price calculation
- Order summary
- Order confirmation
- Form reset

Location:

```text
PizzaRestaurantUI/
```

---

### Login Form

A Windows Forms login interface created to practice validation, timers, and interactive UI behavior.

Features:

- Username and password validation
- Limited login attempts
- Temporary lockout after failed attempts
- Lockout countdown
- Show/hide password
- ErrorProvider validation
- Keyboard navigation
- Date and time display
- UI color and font customization

The credentials used by this project are only demo values stored locally in the application. This is not intended to represent production authentication.

Location:

```text
LoginForm/
```

---

### Employee Management UI

A desktop interface for managing employee records during the application's runtime.

Features:

- Add employees
- Edit employee information
- Delete employees
- Display employee records using ListView
- Multiple ListView display modes
- Employee information such as contact details, department, job title, salary, status, and hire date
- Custom window title bar

The application is focused on UI and Windows Forms practice and does not use a database or permanent data storage.

Location:

```text
EmployeeManagementUI/
```

---

### Stopwatch

A simple borderless stopwatch application.

Features:

- Counts elapsed time
- Pause and resume
- Hours, minutes, and seconds display
- Draggable borderless window
- Minimize support

Location:

```text
Stopwatch/StopwatchApp/
```

## Technologies

- C#
- .NET Framework 4.8
- Windows Forms
- Visual Studio
- Event-driven programming

## Running the Projects

Each project can be opened and run independently in Visual Studio.

Open the corresponding `.sln` file, build the solution, and run the application.

Examples:

```text
TicTacToe/TicTacToe.sln
PizzaRestaurantUI/PizzaRestaurantUI.sln
LoginForm/LoginForm.sln
EmployeeManagementUI/EmployeeManagementUI.sln
Stopwatch/StopwatchApp/Stopwatch.sln
```

## Purpose

These projects were created as practice applications for learning and improving C# Windows Forms development, UI design, event handling, input validation, and application logic.

They are educational desktop projects rather than production applications.
